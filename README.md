# КП 2.4 — TaskFlow

Оновлення проєкту КП 2.3 відповідно до методички КП 2.4.

## Запуск
Відкрийте цю папку через Провідник Windows, введіть `cmd` у адресний рядок. Далі:

```cmd
npm install
npm run dev
```

Сайт: http://localhost:5173/

## Збірка
```cmd
npm run build
npm run preview
```

## Що зроблено
Три основні сторінки, спільна нижня навігація Framework7, іконки, стильові картки, адаптивність, PWA. Додатково: сторінка «Допомога» та показник «Очікує виконання».

## GitHub / Cloudflare
Передайте вихідні файли (не `node_modules`, `dist`) до репозиторію `Oleksii478/my-app`, потім перевірте автоматичний deployment Cloudflare.
